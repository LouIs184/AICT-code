# MSE 与 RMSE 说明

## 定义

### MSE（Mean Squared Error，均方误差）

$$ \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 $$

### RMSE（Root Mean Squared Error，均方根误差）

$$ \text{RMSE} = \sqrt{\text{MSE}} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2} $$

其中：
- $N$ — 像素总数
- $y_i$ — Ground Truth 像素值
- $\hat{y}_i$ — 预测像素值

---

## 区别

| | MSE | RMSE |
|---|---|---|
| **量纲** | 像素值的平方（HU²） | 与像素值同量纲（HU） |
| **数值大小** | 数值较大（平方效应） | 可直观理解 |
| **直观性** | 难以直接解释物理含义 |  ≈ 平均误差大小 |

## 示例

假设 CT 图像 HU 值误差为 50 HU：

$$\text{MSE} = 50^2 = 2500$$

$$\text{RMSE} = \sqrt{2500} = 50$$

RMSE 可以直观理解为 **平均每个像素的误差约 50 HU**，而 MSE 的 2500 在这个语境下没有直接物理含义。

## 在 CT 图像重建中的意义

我们的数据 HU 范围大致在 -1000 ~ 1000，RMSE 值直接反映了重建图像与 Ground Truth 之间 **平均每个像素的 HU 偏差**：

| RMSE | 含义 |
|:----:|------|
| < 30 HU | 重建质量极好，噪声极低 |
| 30 ~ 60 HU | 重建质量良好，轻微噪声/伪影 |
| 60 ~ 100 HU | 有一定误差，结构基本保持 |
| > 100 HU | 误差较大，可能影响诊断 |
