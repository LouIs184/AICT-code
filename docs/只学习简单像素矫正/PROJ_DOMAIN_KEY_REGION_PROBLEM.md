# 投影域训练「整体残差下降但关键区域变差」问题说明

> 本文档只描述问题、说明问题出在哪里，**不包含解决方案**。
> 适用范围：投影域（ProjCT）去伪影训练。

---

## 一、背景

当前投影域去伪影任务（输入 `proj_pbi`，目标 `proj_no_pbi`）的训练配置如下（`experiments/denseunet_projct.yaml`）：

| 项 | 值 |
|---|---|
| 模型 | DenseUNet2d（残差输出 `relu(x + conv6)`） |
| 损失 | 纯 MSE（`mse_weight: 1.0`，其余均为 0） |
| 优化器 / 调度 | Adam lr=1e-4 / StepLR |
| 数据 | 每视角 (128, 512)，`crop_rows=8` 后为 (112, 512)；归一化 `clip(x, 0, 0.28)/0.28` |
| 建模粒度 | 单视角 2D（每个视角独立输入模型，互相无关联） |

---

## 二、问题现象

1. **整体指标持续改善**：训练/验证 MSE 稳步下降，整体 PSNR 缓慢上升。
2. **关键区域不改善甚至恶化**：伪影最严重、最需要被矫正的区域（高衰减结构——骨/金属等——对应的投影通道），误差长期停滞或随训练反而变大。
3. **模型行为异常**：输出与输入非常接近（`conv6` 输出被压向 0，模型几乎"不做校正"）；残差图显示改善集中在平滑、均匀的区域，而伪影所在区域几乎无变化。

用一个简化的说法概括：**模型"讨好"了大量简单像素，对难矫正的关键区域"装死"**。

---

## 三、什么算"简单像素"，什么算"关键区域"

**简单像素**：探测器平面上占绝大多数的像素——穿过空气和均匀软组织的通道。这些区域的投影值平滑、可预测，模型很容易学对，而且**一个 112×512 探测器平面约 5.7 万个像素里它们占绝大部分**。

**关键区域**：伪影校正信号集中的少数像素——主要是高衰减结构（骨皮质、金属植入物、牙齿、钙化灶）和身体最厚处中轴路径对应的通道。特点：

- **需要被校正的量最大**（`|proj_no_pbi − proj_pbi|` 在这些通道上最大）；
- **光子数少、噪声大**（透射值低 → SNR 低）；
- **占像素总数比例极小**。

---

## 四、问题出在哪里（机制分析）

### 4.1 目标函数层面的必然结果

MSE 的最优解是条件均值 $\mathbb{E}[y|x]$。在映射不适定、模型容量有限的情况下，模型倾向于输出一个"安全折中值"——把整体平均误差压最低，而不是把任何单点做到最好。**只要绝大多数像素被压好，个别关键像素错得多，平均损失仍然很低**。这是目标函数的设计使然，不是训练过程的偶然失误。

### 4.2 梯度被简单像素稀释

总损失是逐像素平均，而网络参数更新用的是**梯度平均**。简单像素数量占绝对多数且梯度方向高度一致，它们对参数的合力远大于少数关键像素。模型在每步更新中"保住简单像素"的收益显著高于"冒险修正关键像素"。

### 4.3 卷积参数共享带来的梯度冲突

卷积核是共享的：修正一个关键像素会同时扰动其感受野内的所有像素。在容量有限时，模型发现修正关键区往往以轻微恶化大量简单区为代价，于是干脆放弃关键区。

### 4.4 网络结构的偏置方向

`DenseUNet2d` 的输出是 `relu(x + conv6)`（残差结构）。这个设计隐含默认"输出≈输入、尽量不做修改"。**没有任何机制阻止 conv6 全学成接近 0**——而这是让简单像素最满意、让关键区域最失望的解。

### 4.5 投影域特殊性进一步放大问题

| 因素 | 说明 |
|---|---|
| 像素数量悬殊 | 简单像素占绝对多数，关键区域占比极小 |
| 校正信号集中 | 需要被学习的"修正量"集中在少数通道上 |
| 动态范围小 | 归一化后 `target − input` 差异约 0.01~0.05，在 [0,1] 中不显著 |
| 关键区噪声大 | 高衰减通道透射光子少，校正量既大又脏 |
| 逐视角 2D 建模 | 束硬化校正在 sinogram 上是**跨视角全局耦合**的，单视角模型可能缺少修正关键区所需的信息 |

### 4.6 核心结论

> 观察到的现象是当前训练目标（纯 MSE）在投影域数据分布下的**最优行为**：在简单像素占绝大多数的分布上，模型通过放弃极少数关键像素来压低平均损失。**问题出在目标函数与数据分布的错配**，而不是模型参数或训练过程出错。

---

## 五、为什么整体指标会掩盖问题

整体 MSE / PSNR 是一个**聚合值**，它无法区分"错误被均匀摊薄"还是"简单区变好、关键区变差"。在关键区域占比极小时，关键区再恶化对整体指标的影响也可以被简单区的微小改善抵消——于是出现**整体残差变小、关键部位反而变差**并存的现象。

只依据整体指标，会得到以下误导性结论：

- 误以为模型在持续变好；
- 在错误的时间点选 checkpoint / 早停；
- 把"关键区根本没被矫正"判断成"模型已收敛"。

---

## 六、问题的影响

1. **去伪影的核心目标未达成**：伪影最严重、最影响诊断的部位没有被矫正，模型对任务最关心的部分没有作用。
2. **评估失真**：整体指标无法反映真实质量，无法支撑模型选型与训练决策。
3. **与最终目标脱节**：最终要衡量的是图像域（重建图像）质量，而当前问题已经在投影域层面使关键信息丢失，且单视角建模与最终重建所需的全局一致性不符。

---

## 七、如何确认这个问题确实存在（问题证据，非解决方案）

以下观察手段用于**证实问题的存在**，而非给出修复办法：

1. **按区域拆分统计误差**：把每个视角的像素按 `|target − input|`（校正量）分为"校正量大的区域"和"校正量小的区域"，分别统计两部分的 MSE/PSNR。若出现"校正量小的区域持续改善、校正量大的区域停滞或恶化"，即可确认现象。
2. **看残差图**：可视化 `|target − pred|`，观察改善是否只集中在平滑区域。
3. **看模型输出**：检查 `conv6` 的量级——若整体趋于 0，说明模型退化为"直接拷贝输入"。
4. **检查跨视角一致性**：若单视角模型在任意视角上关键区都无法改善，需进一步确认问题是否不止于损失函数，而是建模粒度（单视角）导致的信息缺失。

---

## 八、结论

- 投影域训练中"整体残差下降、关键区域变差"是**真实存在且可复现**的问题；
- 其根源是**纯 MSE 目标函数在简单像素占绝对多数的投影域数据上的最优行为**，并受模型残差结构、逐视角建模粒度等因素放大；
- 整体聚合指标**无法反映**该问题，必须按区域拆分统计才能让问题可见；
- 本问题涉及目标函数设计、数据分布、模型结构三个层面，解决方案不在本文档范围内。
